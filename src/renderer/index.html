Graphics and hardware

Custom metadata changes the reported GPU names. Graphics capabilities and rendering still come from this machine.

Based on WebGL sets vendor/device metadata; it does not emulate another GPU's features, limits or performance.

Screen and privacy output

Custom mode keeps Windows default fonts and the installed additional fonts you list. It cannot install or create fonts.

Hardware noise

Each switch uses the profile's existing stable seed. Canvas noise can still be detected by known-pixel tests. ClientRects changes reported coordinates slightly; speech protection filters the real voice list.

Network, location and language

Real mode permits direct WebRTC traffic, which may expose the machine's IP. The HTTP proxy relay does not support Proxy UDP or replacing WebRTC IPs.

Based on IP uses the configured proxy's exit location. Without a proxy, it uses the system settings. Custom values override this explicitly. Real location still requires Windows location permission.

Browser behavior and availability

Turning acceleration off can change available graphics APIs and the real renderer.

Graphics APIs and capabilities come from Chromium and the rendering backend. Custom media-device counts, Proxy UDP, port-scan filtering and per-profile TLS-feature changes are not implemented in this build.
